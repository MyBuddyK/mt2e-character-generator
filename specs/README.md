# Test plans

Markdown test plans written by the `playwright-test-planner` agent, or by following its steps, live here.
The `playwright-test-generator` agent turns a plan into specs under `e2e/`.

- [`career-terms.md`](career-terms.md): the career terms feature (`docs/features/career-terms.md`). It maps
  each acceptance criterion to the test that checks it, and its scenarios are the "career terms plan" tests
  in `e2e/career.spec.ts`.
